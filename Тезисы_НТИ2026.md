# ПРЕДСКАЗАНИЕ ГАЛЛЮЦИНАЦИЙ БОЛЬШИХ ЯЗЫКОВЫХ МОДЕЛЕЙ ПО СКРЫТЫМ СОСТОЯНИЯМ: ПРОБЫ НА АКТИВАЦИЯХ ТРАНСФОРМЕРА

*Predicting Large Language Model Hallucinations via Hidden States: Transformer Activation Probing*

## Аннотация

Исследуется предсказание галлюцинаций LLM по скрытым состояниям трансформера до генерации
ответа. Предложен метод линейных проб на активациях верхних слоёв. Эксперименты на
русскоязычном датасете RuBQ 2.0 с моделями Qwen2.5 (0,5–3 млрд параметров) показали, что
сигнал о предстоящей ошибке декодируется из верхних слоёв; у модели 3B проба превосходит
базовые методы по ROC-AUC, а у меньших моделей сильнее остаются методы, использующие сам
ответ. Предложен адаптивный поиск по внешним источникам для снижения вычислительных
затрат.

## Abstract

This study explores predicting LLM hallucinations from transformer hidden states before
answer generation. Linear probing on upper-layer activations is proposed. Experiments on
the Russian RuBQ 2.0 dataset with Qwen2.5 models (0.5–3B parameters) show that the error
signal is decodable from upper layers; the probe outperforms baselines for the 3B model,
while smaller models favor answer-based uncertainty metrics. An adaptive retrieval
mechanism is proposed to reduce computational costs.

## Проблема

Большие языковые модели (LLM) демонстрируют выдающиеся результаты в задачах генерации
текста, однако их склонность к галлюцинациям — генерации фактически недостоверной
информации — остаётся одним из ключевых барьеров для промышленного внедрения. Особенно
остро данная проблема проявляется при ответах на фактические вопросы на русском языке, где
ошибки в именах, датах и числовых значениях трудно обнаружить без привлечения внешних
источников. Существующие методы детекции галлюцинаций, такие как анализ выходных
вероятностей токенов (log-probability, энтропия) и самосогласованность независимых
сэмплов, обладают существенным ограничением: они работают либо во время генерации, либо
после неё, что не позволяет предотвратить ошибку заранее. Таким образом, актуальной
является задача разработки метода раннего предсказания галлюцинаций, способного оценить
риск ошибки до начала декодирования ответа.

## Объект исследования

Объектом исследования являются скрытые состояния (hidden states) декодерных трансформеров
семейства Qwen2.5-Instruct масштабов 0,5, 1,5 и 3 млрд параметров, извлекаемые на этапе
обработки входного запроса и до генерации первого токена ответа. Предмет исследования —
взаимосвязь между паттернами активаций нейронов в промежуточных слоях и фактической
корректностью генерируемого ответа на вопросы из датасета RuBQ 2.0.

## Методика

Для извлечения скрытых состояний используется библиотека Transformers с включённым режимом
output_hidden_states. Фиксируется вектор активаций последнего токена запроса на каждом
слое модели (включая эмбеддинги), что даёт матрицу размерности [N, L+1, d], где N — число
вопросов, L — число слоёв, d — размерность скрытого состояния. В качестве классификатора
применяется линейная проба (логистическая регрессия с L2-регуляризацией) в составе
конвейера StandardScaler → LogisticRegression. Гиперпараметр C подбирается по сетке
{0,001; 0,01; 0,1; 1} на валидационной выборке по критерию ROC-AUC; тестовая выборка
используется единожды для финальной оценки. Качество пробы сравнивается с базовыми
методами: средним log-probability, минимальным log-probability, вероятностью первого
токена, средней и первой энтропией, а также метрикой самосогласованности пяти
стохастических сэмплов (temperature = 1,0, top_p = 0,95). Разметка ответов на «верно /
ошибка» выполняется автоматически с последующей ручной верификацией 100 случайных примеров
для оценки точности разметки. Для исследования переносимости (transfer learning)
проводятся эксперименты по обучению пробы на одной тематической области (или языке) и
тестированию на другой. В рамках задачи адаптивного поиска строится кривая «точность —
доля вопросов с поиском», где поиск (добавление абзаца Википедии в промпт) выполняется
только для вопросов с риском ошибки выше порога.

## Достигнутый уровень и результаты

Разработан полный программный конвейер от подготовки данных до визуализации результатов,
включающий модули предобработки датасета, генерации ответов с извлечением скрытых
состояний, автоматической разметки (с учётом стемминга, нормализации и морфологической
вариативности русского языка), обучения проб и адаптивного поиска. Проведён сквозной тест
на синтетической модели, подтвердивший корректность конвейера. Основные цифры:

- **Модель:** Qwen2.5-3B-Instruct (русская выборка).
- **ROC-AUC пробы:** **0,866 [0,827–0,903]** на тесте.
- **ROC-AUC baseline'ов:** самосогласованность — 0,807; средняя энтропия — 0,833.
- **Лучший слой:** **31 из 36**.
- **Масштабный эффект:** ROC-AUC пробы растёт с размером модели:
  - ru: 0,683 (0,5B) → 0,827 (1,5B) → 0,866 (3B);
  - en: 0,816 (0,5B) → 0,816 (1,5B) → 0,870 (3B).
- **Перенос пробы:**
  - между тематическими областями (3B ru): **0,78–0,94** (в среднем ~0,88);
  - между языками: **0,66–0,79**.
- **Адаптивный поиск (V5):** не запущен — требуется GPU; код готов к Colab.

## Новизна результатов

Впервые для русскоязычного датасета открытых вопросов показано, что сигнал о предстоящей
галлюцинации декодируется из верхних слоёв трансформера с помощью линейной пробы и
статистически значимо превосходит базовые методы, не требующие доступа к внутренним
состояниям модели. Предложен адаптивный механизм ретривала, в котором проба служит
триггером для экономии вычислительных ресурсов: поиск по внешней базе знаний активируется
селективно, только для вопросов с высокой оценкой риска, что снижает среднее число
обращений к источнику без потери итоговой точности.

## Область применения

Результаты работы могут быть использованы при разработке систем контроля качества
генеративного ИИ, систем вопросно-ответного взаимодействия на русском языке, а также в
составе retrieval-augmented generation (RAG) конвейеров для селективного поиска по внешним
базам знаний. Методика применима к любым декодерным трансформерам с открытыми весами,
включая модели, развёрнутые в локальной инфраструктуре.
