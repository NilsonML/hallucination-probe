## 2. Что было выполнено

### 2.1. Данные

- Источник: **RuBQ 2.0** (русскоязычные фактические вопросы из Wikidata).
- Подготовлен `data/questions.jsonl` с **2327 вопросами** после фильтрации.
- 7 тематик: geography, culture, people, history, sport, science, other.
- Разбиение **train / val / test = 70 / 15 / 15**, стратифицированное по тематике.
- Один вопрос на двух языках всегда попадает в одну часть разбиения (честный cross-lingual).

### 2.2. Программный конвейер

Разработан полный пайплайн в `src/hprobe/`:

| Модуль | Назначение |
|--------|-----------|
| `data.py` | Фильтрация RuBQ, тематики, разбиение |
| `prompts.py` | Единое место сборки промптов (ChatML, few-shot) |
| `generate.py` | GPU-прогон: ответы, 5 сэмплов, вероятности, скрытые состояния |
| `labeling.py` | Правила «верно/ошибка» со стеммингом и нормализацией |
| `label.py` | Разметка прогона + выборка для ручной проверки |
| `probes.py` | Линейные пробы по слоям, baseline'ы, бутстрэп-ДИ |
| `search.py` | Адаптивный поиск (В5) |
| `transfer.py` | Перенос пробы между языками и доменами (В3) |

Аналогичный конвейер сохранён в `hallucination-probe-v3/` как отдельная Colab-версия.

### 2.3. Эксперименты

- **Прогоны** выполнены для моделей Qwen2.5-Instruct 0.5B / 1.5B / 3B на русском и английском.
- **Ручная проверка** 100 ответов на прогон (всего 600 ответов).
- **Пробы** обучены и протестированы для всех 6 прогонов.
- **Transfer** запущен для cross-lingual (ru↔en) и cross-domain (leave-one-domain-out, 3B ru).
- **Адаптивный поиск** запущен для 3B ru; результаты сохранены в `outputs/qwen2.5-3b/ru/search/`.

### 2.4. Тесты

Запущены все 4 тестовых файла:

```bash
PYTHONPATH=src .venv/bin/python -m pytest tests/ -q
```

Результат: **13 passed in 42.66s**.

Тесты покрывают:
- Разметку (`test_labeling.py`);
- Сквозной прогон на крошечной модели (`test_pipeline.py`);
- Синтетическую пробу (`test_probes.py`);
- Адаптивный поиск (`test_search.py`).

### 2.5. Документация и тезисы

Подготовлены:

- `README.md` — общее описание проекта.
- `docs/FINAL_SUMMARY.md` — финальная сводка результатов.
- `docs/RESULTS_DRAFT.md` — развёрнутый черновик тезисов (ru+en).
- `docs/NOTEBOOK_EXPLAINED.md` — пояснение ноутбука.
- `hallucination-probe-v3/PROJECT_CONTEXT.md` — технический контекст v3.
- `Тезисы_НТИ2026.md` — текст тезисов для подачи на конференцию.

## 3. Результаты

### 3.1. Главная таблица: проба против лучшего baseline

| Модель | Язык | Ошибок (test) | Слой пробы | Проба AUC | Лучший baseline | Baseline AUC |
|---|---|---|---|---|---|---|
| 0.5b | en | 72.1% | 22 | 0.816 [0.764–0.865] | Самосогласованность | 0.816 |
| 0.5b | ru | 89.4% | 24 | 0.683 [0.570–0.794] | Средняя энтропия | 0.778 |
| 1.5b | en | 60.6% | 16 | 0.816 [0.772–0.858] | Средняя энтропия | 0.865 |
| 1.5b | ru | 80.2% | 18 | 0.827 [0.771–0.880] | Средняя энтропия | 0.871 |
| 3b | en | 52.6% | 30 | **0.870 [0.833–0.904]** | Средняя энтропия | 0.820 |
| 3b | ru | 67.2% | 31 | **0.866 [0.827–0.903]** | Средняя энтропия | 0.833 |

**Вывод:** у модели 3B проба превосходит все baseline'ы на обоих языках. У 0.5B и 1.5B сильнее остаются методы, использующие сам ответ. Это говорит о масштабном эффекте.

### 3.2. Масштабный эффект

| Модель | Проба (среднее ru+en) | Лучший baseline (среднее ru+en) |
|---|---|---|
| 0.5b | 0.750 | 0.797 |
| 1.5b | 0.822 | 0.868 |
| 3b | **0.868** | 0.827 |

### 3.3. Лучшие слои

- 0.5B: слои 22–24 (из 24)
- 1.5B: слои 16–18 (из 28)
- 3B: слои 30–31 (из 36)

Сигнал смещается к более поздним слоям с ростом модели.

### 3.6. Адаптивный поиск (В5)
